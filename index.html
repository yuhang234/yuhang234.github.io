VoiceNote — 离线语音记录引擎

“想到什么直接说 —— Windows 桌面语音记录工具，启动即自动监听，本地离线转文字并按日期归档。”

  • 零唤醒交互成本：常驻 Windows 系统托盘静默监听，无需任何多余点击即可随时捕捉灵感。
  • 高效双阶流水线：轻量 Silero VAD（本地 CPU）毫秒级过滤静音，触发人声后唤醒 faster-whisper（GPU CUDA）。
  • 极致端侧性能基准：实测 large-v3-turbo 在 RTX 4060 CUDA 上 RTF 达到 0.18（~5.5 倍实时识别），停顿约 0.7 秒出字。
  • 无损本地持久化：每日自动生成独立 Markdown 记录文件，配套 FLAC 无损音频，点击即可原声回放。

NoteFlow — 本地优先 Markdown 桌面系统

“本地优先（Local-First）Markdown 桌面笔记系统。以纯本地 .md 文件为唯一权威数据源，支持 SQLite FTS5 全文检索、多维时间线/日历/地图视图与完整离线运行。”

  • 严格的 Local-First 准则：拒绝封闭数据库绑定，每篇笔记真实对应独立 .md 文件，完全兼容外部编辑器且双向热同步。
  • 双核存储与毫秒级索引：数据库仅作为派生缓存，集成 SQLite FTS5 引擎实现万级笔记的亚毫秒级全文模糊搜索。
  • 现代高生产力渲染栈：基于 React 19 + CodeMirror 6 双栏实时渲染，原生集成 LaTeX 公式离线渲染与本地多媒体资产库。
  • 多维时空回溯：内置瀑布流多列时间线、月度日历分布、多层级标签网络与近 120 天写作热力图。
