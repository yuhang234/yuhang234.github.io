## 核心代表作
- **[VoiceNote](https://github.com/yuhang234/VoiceNote)** (Python): Windows 桌面语音记录工具，启动即自动监听，本地离线转文字并按日期归档。基于 faster-whisper + Silero VAD，CUDA RTF 达 0.18。
- **[NoteFlow](https://github.com/yuhang234/NoteFlow)** (Tauri 2 + Rust + React 19): 本地优先 Markdown 桌面笔记系统，纯本地 .md 文件为权威数据源，SQLite FTS5 全文检索，多维时间线/日历/地图视图，完全离线运行。
- **[TeamFlow](https://github.com/yuhang234/TeamFlow)** (Vue 3 + FastAPI): 面向高校课设协同的团队协作平台，任务管理、协作记录、贡献度分析与内置 TeamFlow AI 智能助手服务。

## 技术栈与特性
- **纯原生技术栈**：原生 HTML5 + CSS3 + ES6+ JavaScript，零构建、零依赖、零打包步骤，直接托管于 GitHub Pages。
- **极客暗黑主题**：精心打磨的科技暗黑色彩系统、玻璃拟态导航栏、鼠标流光跟踪、粒子场与卡片 3D 透视交互。
- **纯 CSS 架构拓扑流图**：系统流程图完全由原生 CSS 弹性盒模型绘制，不依赖外部大型图片，毫秒级即时加载。
- **动态数据与降级容错**：集成 GitHub REST API 实时统计动态数据，在无网或频控时提供稳健的优雅降级。
